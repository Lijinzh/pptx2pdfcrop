Install and start

Platform requirement: Windows 10/11 and desktop Microsoft PowerPoint. macOS, Linux, PowerPoint for the web, and WPS are not supported.

Fastest: give one sentence to Codex

On this Windows PC, install the latest pptx2pdfcrop from https://github.com/Lijinzh/pptx2pdfcrop, run pptx2pdfcrop doctor to verify desktop Microsoft PowerPoint automation, then tell me where it was installed and give me one example that exports slide 9 as a tightly cropped PDF.

Manual install

uv tool install git+https://github.com/Lijinzh/pptx2pdfcrop.git
pptx2pdfcrop doctor

Export modes

vector: default and recommended

PowerPoint exports a native PDF. A high-resolution rendering is used only for boundary detection; the final file translates the original PDF content and resets its page boxes, preserving vector text and paths.

compatible: fallback for complex effects

PowerPoint renders high-resolution TIFF files. The tool crops them and embeds JPEG 4:4:4 or LZW TIFF data in an image PDF for more consistent transparency, gradients, and soft masks.

pptx2pdfcrop export drawing.pptx --slides 9 --mode compatible
pptx2pdfcrop export drawing.pptx --slides 9 --mode compatible --compression lossless

Complete implementation logic

The CLI builds immutable ExportOptions. A shared pipeline validates inputs, selects a mode, manages temporary files, and atomically commits the final output. PowerPoint runs in a private hidden instance that is always closed.

1. CLI and slide parsingcli.py parses options; pages.py normalizes expressions such as 1,3-5.
2. Shared pipelinepipeline.py validates platform, paths, DPI, thresholds, and compression, then creates a temporary workspace.
3. PowerPoint backendpowerpoint.py uses pywin32 COM to open the source read-only and export selected slides to PDF or TIFF.
4. Content detectiongeometry.py finds non-white RGB pixels, expands safety padding, and rejects blank pages.
5A. Vector cropvector_pdf.py renders through PDFium for detection, then uses pypdf to translate native content and reset page boxes.
5B. Compatible encodingraster_pdf.py crops TIFF, saves JPEG 4:4:4 or LZW TIFF, and embeds it without a second lossy pass.
6. Safe commitThe candidate is validated, atomically moved with os.replace, and all temporary data is removed.

Why copy and trim the presentation?

PowerPoint print ranges can be affected by custom starting slide numbers. A temporary copy is trimmed from the end so the source is untouched and selected indexes remain correct.

Why render in vector mode?

Rendering is only a measuring step. The final file still contains the original PDF content streams.

Contribute code

Set up development

git clone https://github.com/Lijinzh/pptx2pdfcrop.git
cd pptx2pdfcrop
uv sync --extra dev
uv run ruff check .
uv run pytest
uv build
uv run pptx2pdfcrop doctor

Unit tests do not launch PowerPoint. End-to-end export checks require Windows with desktop PowerPoint installed.

Before submitting

  • Do not commit test presentations, paper figures, temporary TIFFs, or generated PDFs.
  • Cover pure-white pages, near-white gradients, and zero-padding when changing crop logic.
  • Document file-size and zoomed-quality changes when adjusting DPI, JPEG quality, or chroma sampling.
  • Keep PowerPoint in a private instance, open sources read-only, and close COM resources on every exit path.
  • Keep Simplified Chinese public docs primary and synchronize necessary English content.
  • Check website changes at 1440px desktop and 390px mobile.

Pull requests should explain

  1. The problem being solved;
  2. The presentation and slides used for verification;
  3. DPI, compression, and file-size changes;
  4. Whether vector or compatible behavior changes.

Limits and troubleshooting

  • doctor fails: use Windows and install desktop Microsoft PowerPoint.
  • Export misses recent edits: save the presentation first; the tool reads the on-disk version.
  • Transparency differs: repair the source if possible, then try --mode compatible.
  • Edges are clipped: increase --padding and keep --white-threshold 255.
  • Output exists: choose another path or explicitly use --force.
