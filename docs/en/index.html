The pipeline is built around publication figures: select pages, preserve PowerPoint's native rendering quality, then tighten the PDF page boxes using high-resolution content detection.

Clear dependencies. Clear boundaries.

This tool focuses on reliable Windows + PowerPoint export. It does not pretend to be a cross-platform Office converter.

  • Windows only. macOS, Linux, PowerPoint for the web, and WPS are not supported.
  • The default output uses PowerPoint's PDF renderer, so special-effect rendering still depends on PowerPoint.
  • If complex transparency, gradients, or soft masks differ between readers, explicitly use --mode compatible.
  • The tool reads the presentation version saved on disk. It does not save open edits for you.
