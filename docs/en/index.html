The complete pipeline behind one command.

PowerPoint handles rendering. A testable Python pipeline handles slide selection, content detection, page-box tightening, and safe output.

  1. 01

    Parse slides and options

    Resolve 3,5,9-12 or all, then validate output, threshold, DPI, and compression settings.

  2. 02

    Export through PowerPoint

    Open the source read-only in a private hidden instance. Vector mode produces PDF; compatible mode produces high-resolution TIFF.

  3. 03

    Detect content and tighten pages

    Find non-white pixels in a high-resolution rendering. Vector mode only translates content and resets PDF page boxes.

  4. 04

    Write the final PDF atomically

    Finish inside a temporary directory, validate the candidate, replace the target, clean intermediates, and always close PowerPoint.
