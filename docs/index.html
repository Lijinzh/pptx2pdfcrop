从幻灯片到论文插图，只保留内容本身。

Windows-only CLI。直接调用 Microsoft PowerPoint，把指定幻灯片导出为高质量 PDF，并自动裁掉四周白边。

安装并开始 查看源码 ↗
PS> pptx2pdfcrop export drawing.pptx --slides 3,5,9-12

CROPPED.PDF

一条命令，完成三件事。

整个流程围绕论文插图导出设计：选择页面、让 PowerPoint 保留原生渲染质量，再用高分辨率内容检测收紧 PDF 页面框。

01

选择需要的幻灯片

支持单页、逗号列表、连续范围以及全部页面。

02

由 PowerPoint 原生导出

默认保留文字、路径和绘图对象，不把整页栅格化。

03

检测边界并裁掉白边

只调整页面边界和内容位置，输出可直接进入 Word、LaTeX 或投稿系统。

矢量优先，兼容模式兜底。

默认路径服务于清晰度与可编辑性；复杂透明、渐变或特殊效果交给 PowerPoint 的 TIFF 渲染结果扁平化。

当前选择：vector。默认保留 PowerPoint 原生 PDF 中的文字、路径和绘图对象。

开始只需要三行。

通过 GitHub 安装，先检查 PowerPoint 自动化环境，再导出指定页面。

PS> uv tool install git+https://github.com/Lijinzh/pptx2pdfcrop.git
PS> pptx2pdfcrop doctor
PS> pptx2pdfcrop export drawing.pptx --slides 9
WINDOWS 10 / 11依赖 Windows COM 自动化。
MICROSOFT POWERPOINT必须安装桌面版 PowerPoint。
PYTHON 3.10+推荐通过 uv tool 安装。

依赖明确，边界也明确。

这个工具专注于 Windows + PowerPoint 的可靠导出，不假装是跨平台 Office 转换器。

  • 仅支持 Windows，不支持 macOS、Linux、PowerPoint 网页版或 WPS。
  • 默认使用 PowerPoint 的 PDF 渲染结果；特殊效果的最终表现仍取决于 PowerPoint。
  • 复杂透明、渐变或软遮罩出现阅读器差异时，请显式使用 --mode compatible。
  • 工具读取磁盘中已经保存的演示文稿版本，不会替你保存正在编辑的内容。
